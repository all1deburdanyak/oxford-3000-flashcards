# İngilizce Flash Kartlar

iPad ve diğer tarayıcılarda kullanılabilen İngilizce kelime çalışma uygulaması.

- Kartı sola kaydır: sonraki kelime
- Kartı sağa kaydır: önceki kelime
- Kartı yukarı kaydır: öğrendiklerime ekle
- Her kelime için cihazda saklanan kişisel notlar

Notlar ve öğrenilen kelimeler tarayıcının yerel depolamasında tutulur; GitHub'a gönderilmez.
